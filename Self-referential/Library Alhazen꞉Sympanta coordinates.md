**Sympanta coordinates** are a proposed system used by Library Alhazen to name individual [sympanta](../523/Sympan.md). The coordinates are measured from the founder's sympan and are used for naming, not for intersympantic travel.

## Format  
A sympan is identified by three integers written in parentheses and separated by commas, as in (0, 0, -2). Negative values are written with a hyphen. The founder's sympan is (0, 0, 0) and serves as the origin of the system. Every other coordinate is measured from it, so the coordinates are relative to the founder's sympan and do not describe an absolute position.  
  
The coordinates are based on the arrangement described in the [Proposed sympanta geometry](../501/Proposed%20sympanta%20geometry.md).  
  
## Coordinate rule  
A set of coordinates is valid when all three values share the same parity, so that  
  
x ≡ y ≡ z (mod 2)  
  
Each coordinate is therefore either all even or all odd. (1, 1, 1), (2, 0, 0), and (3, 1, 1) are valid, while (1, 1, 0) is not.  
  
## Distance and divergence  
The distance of a sympan from (0, 0, 0) is the length of its coordinates, √(x² + y² + z²). The Library regards distance from the founder's sympan as a rough indication of how much a sympan's history and macroscopic state diverge from those of the founder's sympan. Divergence increases with distance. This is an approximation and not a measurement, since the criteria for classifying divergence have not been established.
